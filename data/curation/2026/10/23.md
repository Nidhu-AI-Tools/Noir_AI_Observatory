# NVIDIA expands model portfolio; llama.cpp adds quantization support

NVIDIA released three new models: CWIP-1.0 (gated), EgoHand-v1, and RT-DETR-Hand-Detector-v1. Concurrently, llama.cpp prereleases added Q2_0 WebGPU support and LoRA optimizations. Research highlights adaptive recursion for recommendations and in-context physics calibration for world models.

## CWIP-1.0 · initial-release

NVIDIA published CWIP-1.0. Release kind: initial-release. Version: ea6e382e7bac064e2e495976a89735fa0bbcab06. Availability: gated.

**Why it matters:** Adds a new gated model to the NVIDIA ecosystem, expanding options for users requiring specific capabilities while maintaining access control.

[Source](https://huggingface.co/nvidia/CWIP-1.0)

## EgoHand-v1 · initial-release

NVIDIA published EgoHand-v1. Release kind: initial-release. Version: 4c90fd1bd774a794ce7492c0091736d580e6e6b7. Availability: downloadable.

**Why it matters:** Provides a new downloadable model focused on hand detection, potentially useful for robotics and gesture recognition applications.

[Source](https://huggingface.co/nvidia/EgoHand-v1)

## RT-DETR-Hand-Detector-v1 · initial-release

NVIDIA published RT-DETR-Hand-Detector-v1. Release kind: initial-release. Version: 2797f7c9ae2901b71a20e732aed6d95099cb8ce9. Availability: downloadable.

**Why it matters:** Introduces a real-time detection variant, offering faster inference capabilities for latency-sensitive hand tracking tasks.

[Source](https://huggingface.co/nvidia/RT-DETR-Hand-Detector-v1)

## Think Harder Where It Matters: Item-Level Adaptive Recursion for Sequential Recommendation

Proposes LoopRec, which uses item-level adaptive recursion to allocate computational budget based on convergence needs rather than fixed depth.

**Why it matters:** Challenges the de facto fixed-depth design in sequential recommenders, potentially improving efficiency and quality by focusing compute where it matters most.

[Source](https://arxiv.org/abs/2610.30128v1)

## PhysiCalWorld: In-Context Physics Calibration for World Models

Proposes PhysiCalWorld, which calibrates action-conditioned world models to instance-specific dynamics via in-context prompting without fine-tuning.

**Why it matters:** Addresses severe drift in novel test scenes by grounding predictions in actual physical behavior through compact descriptors, improving planning accuracy.

[Source](https://arxiv.org/abs/2610.30125v1)
