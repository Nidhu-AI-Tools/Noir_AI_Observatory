# Model Releases and GitHub Updates

NVIDIA and Qwen released new models, while GitHub saw updates to the LLaMA inference engine.

## NVIDIA Releases GLM-5.2-NVFP4

NVIDIA published GLM-5.2-NVFP4, a language model with 4-bit precision.

**Why it matters:** This release brings improved efficiency and performance to NVIDIA's language models.

[Source](https://huggingface.co/nvidia/GLM-5.2-NVFP4)

## Qwen Releases Qwen3.8-Flash-Next-FP8

Qwen published Qwen3.8-Flash-Next-FP8, a multimodal model with open-weights and downloadable availability.

**Why it matters:** This release expands Qwen's multimodal capabilities and enables more flexible deployment options.

[Source](https://huggingface.co/Qwen/Qwen3.8-Flash-Next-FP8)

## LLaMA Inference Engine Update

The LLaMA inference engine saw updates to its Vulkan implementation, including top-k radix select for k >= 1024.

**Why it matters:** These updates improve the performance and efficiency of the LLaMA inference engine.

[Source](https://github.com/ggml-org/llama.cpp/releases/tag/b10712)

## LLaMA Inference Engine Update

The LLaMA inference engine saw updates to its Hexagon implementation, including a fix for a CPY fence bug.

**Why it matters:** These updates address performance issues and improve the stability of the LLaMA inference engine.

[Source](https://github.com/ggml-org/llama.cpp/releases/tag/b10711)

## LLaMA Inference Engine Update

The LLaMA inference engine saw updates to its Metal implementation, including remaining Q4_1/Q5_0/Q5_1 fa-vec tunings for M2.

**Why it matters:** These updates improve the performance and efficiency of the LLaMA inference engine.

[Source](https://github.com/ggml-org/llama.cpp/releases/tag/b10710)
