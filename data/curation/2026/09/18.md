# Recent Developments in AI Research and Model Releases

This daily note summarizes recent research papers and model releases in the field of artificial intelligence. NVIDIA published several updates to their Cosmos3 models, while researchers published papers on tokenization algorithms and zeroth-order preference alignment.

## Objective vs. Search: Decomposing What Makes a Good Tokeniser

Researchers introduced two new tokenization algorithms that complete the 2x2 design space, and found that the search procedure, not the objective, is the dominant factor in achieving lower bits-per-byte.

**Why it matters:** This study provides concrete guidance for the principled construction of tokenizers, which is essential for language modeling performance.

[Source](https://arxiv.org/abs/2609.19145v1)

## A Zeroth-Order Paradigm for LLM Preference Alignment

Researchers proposed a zeroth-order alignment method based on comparison oracles, which extracts directional information from preference pairs without directly optimizing a differentiable preference loss.

**Why it matters:** This method offers improvements over existing direct alignment methods, including length-controlled win rates, and mitigates likelihood displacement.

[Source](https://arxiv.org/abs/2609.19144v1)

## DeepSeek-V4.1-Flash-NVFP4 · initial-release

NVIDIA published DeepSeek-V4.1-Flash-NVFP4, a multimodal model with 8-bit quantization.

**Why it matters:** This release provides a new model for multimodal tasks, which can be used for inference and other applications.

[Source](https://huggingface.co/nvidia/DeepSeek-V4.1-Flash-NVFP4)

## Cosmos3-Edge-Policy-DROID · update

NVIDIA published an update to Cosmos3-Edge-Policy-DROID, a policy model for edge devices.

**Why it matters:** This update provides improved performance and efficiency for edge devices, which is essential for real-world applications.

[Source](https://huggingface.co/nvidia/Cosmos3-Edge-Policy-DROID)

## b11012

The LLaMA.cpp team released b11012, a prerelease with several bug fixes and improvements.

**Why it matters:** This release provides a stable and efficient inference engine for LLaMA models, which is essential for real-world applications.

[Source](https://github.com/ggml-org/llama.cpp/releases/tag/b11012)
