# LLaMA model updates and revisions

Recent updates to the LLaMA model, including new releases and revisions, have been observed.

## b10853 release

Release b10853 of the LLaMA model includes support for Kimi-K3 recurrent-state rollback.

**Why it matters:** This update improves the model's performance and stability, particularly in inference tasks.

[Source](https://github.com/ggml-org/llama.cpp/releases/tag/b10853)

## b10852 release

Release b10852 of the LLaMA model adds RELU and LEAKY_RELU ops to the hexagon.

**Why it matters:** This update enhances the model's capabilities and flexibility in processing different types of data.

[Source](https://github.com/ggml-org/llama.cpp/releases/tag/b10852)

## b10850 release

Release b10850 of the LLaMA model initializes the L2_NORM batch array in tests.

**Why it matters:** This update improves the model's testing and validation processes, ensuring its accuracy and reliability.

[Source](https://github.com/ggml-org/llama.cpp/releases/tag/b10850)

## Mistral-Small-4-119B-2603-NVFP4 revision
