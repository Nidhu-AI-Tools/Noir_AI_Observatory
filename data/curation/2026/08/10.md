# GitHub Releases for LLaMA Inference Engine

Two new stable releases (b10333 and b10332) were made to the LLaMA inference engine on GitHub.

## Release b10333

Stable release with fix for missing Q5_0 dispatch in SpaceMiT backend.

**Why it matters:** This update improves the performance of the LLaMA inference engine on certain hardware configurations.

[Source](https://github.com/ggml-org/llama.cpp/releases/tag/b10333)

## Release b10332

Stable release with removal of redundant comment and fix for isolate working directory.

**Why it matters:** This update improves the stability and reliability of the LLaMA inference engine.

[Source](https://github.com/ggml-org/llama.cpp/releases/tag/b10332)

## Release b10331

Stable release with fix for isolate working directory and removal of redundant comment.

**Why it matters:** This update improves the stability and reliability of the LLaMA inference engine.

[Source](https://github.com/ggml-org/llama.cpp/releases/tag/b10331)
