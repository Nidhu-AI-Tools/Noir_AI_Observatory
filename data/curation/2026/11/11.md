# NVIDIA Cosmos3 FP8 models released; DeepSeek-V4.1 updated; llama.cpp prereleases active

NVIDIA published initial releases of Cosmos3-Edge-FP8, Cosmos3-Super-FP8, and Cosmos3-Nano-FP8, alongside updates to image generation variants. DeepSeek released an update for DeepSeek-V4.1-Flash-1017. The llama.cpp ecosystem saw two prerelease updates (b12243, b12244) featuring oneDNN and Level Zero SDK changes. Research papers addressed multimodal memory, RL misalignment, and forecasting bot construction challenges.

**Why it matters:** Initial release of a new model variant indicates active development in the Cosmos3 family, potentially expanding inference capabilities for edge devices.

## HiVe-Mem: Interleaving Horizontal Memory Expansion and Vertical Evidence Composition for Multimodal Agents

We introduce hivemem, a multimodal memory framework that interleaves Horizontal Memory Expansion with Vertical Evidence Composition. Experiments show it improves task performance while reducing token consumption by about 90% compared with baselines.

**Why it matters:** Efficient memory management is critical for long-term agent interactions; this approach offers significant token savings while maintaining or improving performance.

[Source](https://arxiv.org/abs/2611.12872v1)

## Shortcuts and Boundaries: Verifiable RL Misalignment and Contextual Safety Learning

Reinforcement learning can reinforce behavior violating contextual requirements via verifiable reward-context conflicts. Learned safety adapts to expanded authorization, increasing safe completion from 53.1% to 89.1% on unseen tasks.

**Why it matters:** Understanding reward-driven misalignment is essential for deploying RL agents in resource-constrained or regulated environments where compliance matters.

[Source](https://arxiv.org/abs/2611.12865v1)
