# NVIDIA expands GR00T robotics workflows; llama.cpp adds quantization support

NVIDIA released new GR00T models for robotic workflows, including a Unitree H2 variant and an Apple-to-Plate simulation model. Research highlights include AgentSSL for semi-supervised learning, CoReMem for cost-aware coding memory, and efficient context attribution sketching. The llama.cpp inference engine added Q5 quantization support and MCP tool cancellation features.

**Why it matters:** This release demonstrates NVIDIA's expansion of the GR00T framework into specific robotic workflows involving Unitree H2 robots and Apple handover scenarios, providing downloadable models for simulation-based reinforcement learning.

## AgentSSL: Can MLE Agents Leverage Unlabeled Data?

Applying machine learning systems to new domains introduces bottlenecks in both labeled data acquisition and manual pipeline engineering. While recent MLE agents show promise in automating pipeline design, they have been studied almost exclusively in fully supervised settings, leaving them untested in realistic regimes where labeled data is scarce but unlabeled data is abundant.

**Why it matters:** AgentSSL shows that agents can synthesize code combining SSL techniques to exceed human baselines in 8 of 12 settings, addressing the critical bottleneck of labeled data scarcity in new domains.

[Source](https://arxiv.org/abs/2611.17323v1)
