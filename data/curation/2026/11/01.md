# NVIDIA releases DeepSeek-V4.1-Flash quantized model; llama.cpp and Hugging Face see updates

DeepSeek-V4.1-Flash-1017-NVFP4 was released as an initial multimodal inference model with FP4 quantization by NVIDIA. Google updated gemma-4-12B and its instruction-tuned variant. NVIDIA also published three Cosmos3-Nano-Sim updates for simulation tasks. The llama.cpp ecosystem saw multiple prerelease builds, including OpenCL support and reasoning format adjustments. Hugging Face released a patch update for the transformers library.

## DeepSeek-V4.1-Flash-1017-NVFP4 · initial-release

NVIDIA published DeepSeek-V4.1-Flash-1017-NVFP4. Release kind: initial-release. Version: 480550d349ede47a048eb65a276c5c01a06256e2. Availability: downloadable. Categories: multimodal.

**Why it matters:** This release introduces a quantized multimodal model optimized for inference, potentially expanding the accessibility of advanced vision-language capabilities on resource-constrained hardware.

[Source](https://huggingface.co/nvidia/DeepSeek-V4.1-Flash-1017-NVFP4)
