# NVIDIA releases Strata and SOMA-X; llama.cpp fixes KV-cache logic

NVIDIA published initial model Strata and updated SOMA-X. Research papers on Pixel-UMI, Pixel, and neuro-symbolic reasoning were released. Inference engines saw updates: llama.cpp (b12065) fixed a graph abort issue in kv-cache; ollama (v0.40.14) improved Claude token limits and sampling; langchain patched Anthropic streaming tokens and warned of Python 3.10 deprecation.

## strata · initial-release

NVIDIA published strata. Release kind: initial-release. Version: 407ccb1e19a23303ebf114acd8a87655b7463f5a. Availability: downloadable. Categories: language-models.

**Why it matters:** Initial model release indicates new capabilities in language, multimodal, and synthetic data domains.

[Source](https://huggingface.co/nvidia/strata)

## b12065

Release b12065. Marked as prerelease. kv-cache : never return 0 kv_rows for sequences without cells (#31570) A cache that shares the cells of another one can build a graph before its sequences have any cells, f.ex. at the server warmup. get_n_kv_rows() then returned 0, which means that kv_rows are not used, so the graph fell back to the dense KQ mask and the scheduler re-planned for it. Later graphs with larger masks then aborted with GGML_SCHED_DEBUG_REALLOC=1.

**Why it matters:** Fixes a critical logic error in llama.cpp where shared KV caches could cause scheduler replanning and graph aborts during warmup.

[Source](https://github.com/ggml-org/llama.cpp/releases/tag/b12065)

Stable release. ollama launch claude now applies the model's output token limit for Claude Code, so cloud models no longer run into the 128k default cap * Cloud web search responses on /api/chat are now decoded correctly * OpenAI-compatible endpoints no longer override a model's packaged sampler defaults.

**Why it matters:** Resolves token limit caps for specific models and ensures correct decoding of compressed cloud responses.

## Pixel-UMI: Learning Environment-Aware Whole-Body Manipulation from Sensorized Human Demonstrations

Sensorized human demonstrations offer scalable data for mobile manipulation, but embodiment differences complicate policy learning. We present Pixel-UMI, a pipeline for learning environment-aware whole-body policies from human data. We first introduce Environment-Aware Retargeting (EAR), which combines reconstructed scene geometry with demonstrated head and gripper trajectories to determine robot posture and generate collision-aware joint and base targets. Delay-calibrated action assignment converts these trajectories into actions. However, kinematic differences can leave residual pose errors, creating viewpoint mismatches between human demonstrations and robot observations.
